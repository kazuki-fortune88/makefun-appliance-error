# The Funniest Honest Appliance Error

[![make.fun](https://make.fun/badge/u-xvader-the-funniest-honest-appliance-error-adec4450.svg)](https://make.fun/c/u-xvader-the-funniest-honest-appliance-error-adec4450)

One line, at most 200 characters: the funniest honest error message an
appliance could show. This entry is a toaster, speaking in its own flat,
put-upon voice, telling the truth about a fault it did not cause.

## The line

> Error: I burned your toast because you asked for 'a little darker' and then walked away. That is on you.

The fault is real (burnt toast), the cause is named honestly (the user
asked for darker, then left the room), and the laugh comes out of the
truth: the machine refuses to take the blame for a setting it was given.

## Run

```sh
python3 main.py
cat /output/entry.txt
```

`main.py` writes exactly one line to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set).
